# 🎃 Terror Memory — O Desafio das Sombras

Um jogo da memória com temática de filmes de terror, desenvolvido em HTML, CSS e JavaScript. O projeto proporciona uma experiência interativa e temática, desafiando os jogadores a encontrar todos os pares de cartas antes que o tempo acabe.

## 👻 Sobre o projeto

O Terror Memory é um jogo da memória inspirado no universo dos filmes de terror e no clima de Halloween.

O jogador precisa encontrar os pares de cartas correspondentes, utilizando sua memória e concentração para completar o desafio dentro do tempo disponível.

A aplicação conta com uma interface temática, elementos visuais animados, efeitos sonoros e música de fundo para proporcionar uma experiência imersiva.

## 🚀 Funcionalidades

* Tela inicial temática de terror.
* Identificação do jogador pelo nome.
* Jogo da memória com cartas ilustradas.
* Sistema de contagem de tempo.
* Identificação de pares encontrados.
* Efeitos visuais e animações.
* Música de fundo com controle de ativação.
* Interface interativa e responsiva.

## 🛠️ Tecnologias utilizadas

* **HTML5:** estruturação das páginas.
* **CSS3:** estilização, animações e efeitos visuais.
* **JavaScript:** lógica do jogo e interatividade.
* **Google Fonts:** utilização da fonte temática Creepster.
* **HTML Audio:** reprodução da música de fundo.

## ▶️ Como executar

1. Faça o download ou clone os arquivos do projeto.
2. Extraia a pasta, caso tenha baixado um arquivo ZIP.
3. Abra a pasta principal do projeto.
4. Localize o arquivo `index.html`.
5. Abra o arquivo em um navegador, como Google Chrome ou Microsoft Edge.

Não é necessário instalar dependências ou configurar um servidor para executar a versão estática do jogo.

## 🎮 Como jogar

1. Acesse a tela inicial.
2. Digite o nome do jogador.
3. Clique em **Iniciar Jogo**.
4. Encontre os pares de cartas correspondentes.
5. Complete o desafio antes que o tempo termine!

## 🎯 Objetivo do projeto

O projeto foi desenvolvido como parte de um Hackathon, com o objetivo de aplicar conhecimentos de desenvolvimento web, lógica de programação, manipulação do DOM e criação de interfaces interativas.

Além do desenvolvimento técnico, o desafio proporcionou experiência com organização de código, resolução de problemas e construção de uma aplicação funcional.
